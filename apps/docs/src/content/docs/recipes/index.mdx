Engine. Each one uses code from a tested example in the Invokta repository, then
shows how to run and verify the result locally.

## Before you start

Run the recipes from the repository root with Node.js 22.20.0 or later and Yarn
1.22.22:

```sh
git clone https://github.com/vinilana/ai-engines.git
cd ai-engines
yarn install --frozen-lockfile
yarn build
```

If this is your first Invokta engine, build the
[first-engine walkthrough](/getting-started/first-engine/) before using these
patterns. Browse the [complete example catalog](/examples/) when you want to
compare domains, provider boundaries, and workflow designs.
